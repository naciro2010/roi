# ROI — Le réseau qui rapporte

Application mobile-first de networking pour entrepreneurs qui courent.
Un mélange de **LinkedIn**, **Strava** et **Happn** au design épuré et professionnel :
on participe à des sorties course pour rencontrer du monde, on se fait
matcher avec les bonnes personnes, et on crée des groupes pour échanger.

## Fonctionnalités

- **Accueil** — tableau de bord « ROI réseau » : score, connexions, RDV, opportunités, prochain match et prochaine sortie.
- **Réseau** — matchs intelligents (score + contexte partagé) et annuaire des membres avec recherche et filtres.
- **Fiche membre** — bio, ce qu'il/elle cherche & propose, connexions communes, mise en relation.
- **Agenda** — défi du mois, classement, et sorties détaillées (distance, allure, niveau, lieu, participants).
- **Messages** — discussions 1:1 et **groupes** (création, découverte, chat de groupe).
- **Profil** — besoins éditables, statistiques running, centres d'intérêt, communauté.

## Stack

React 18 · Vite · Tailwind CSS. Données fictives, aucune dépendance back-end.

## Démarrer

```bash
npm install
npm run dev      # serveur de développement
npm run build    # build de production
```
